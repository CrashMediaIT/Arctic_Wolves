# Unused Files Archive

This directory contains files that are not actively used in the current Arctic Wolves application but are preserved for reference and historical purposes.

## Purpose

The `/unused/` directory mirrors the structure of the root directory and serves as an organized archive for:
- Historical documentation and reports
- Deprecated code files (if any are identified in the future)
- Backup files
- Legacy features that may be re-implemented later

## Directory Structure

This directory maintains the same structure as the application root:
- `/unused/QA/` - Historical QA reports and documentation
- `/unused/admin/` - Unused admin utilities
- `/unused/backups/` - Old backup files
- `/unused/cache/` - Deprecated cache files
- `/unused/config/` - Old configuration files
- `/unused/css/` - Deprecated stylesheets
- `/unused/deployment/` - Old deployment scripts
- `/unused/goals/` - Deprecated goals module files
- `/unused/js/` - Unused JavaScript files
- `/unused/lib/` - Deprecated library files
- `/unused/logs/` - Old log files
- `/unused/receipts/` - Archived receipts
- `/unused/tmp/` - Old temporary files
- `/unused/uploads/` - Deprecated uploads
- `/unused/videos/` - Archived videos
- `/unused/views/` - Unused view templates
